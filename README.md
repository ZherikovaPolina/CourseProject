
# CalorieCalc

**CalorieCalc** - настільний застосунок для розрахунку калорійності та харчової цінності продуктів.

Програма дозволяє обирати продукти з каталогу, вказувати їхню вагу, розраховувати калорії, білки, жири та вуглеводи (БЖВ), а також створювати власні продукти.

Застосунок має зручний графічний інтерфейс і використовує локальну базу даних SQLite для збереження інформації.

## Основні можливості

- Пошук продуктів за назвою.
- Каталог із 40 стандартних продуктів.
- Розрахунок калорійності та БЖВ залежно від ваги продукту.
- Додавання декількох продуктів до одного розрахунку.
- Автоматичний підрахунок загальної калорійності та БЖВ.
- Створення власних продуктів.
- Редагування та видалення власних продуктів.
- Захист стандартних продуктів від редагування та видалення.
- Збереження інформації в базі даних SQLite.
- Автоматичне відновлення списку продуктів після перезапуску.
- Перевірка коректності введених даних.

## Встановлення та запуск

### Вимоги

Для запуску проєкту з вихідного коду необхідно встановити:

- Node.js
- npm
- Git

### Клонування репозиторію

```bash
git clone https://github.com/ZherikovaPolina/CourseProject.git
cd CourseProject
```

```bash
npm install
```

### Запуск застосунку

```bash

```

Після виконання команди відкриється вікно CalorieCalc.

## Інструкція користувача

### Розрахунок калорійності

1. Запустіть CalorieCalc.
2. У полі пошуку введіть назву продукту.
3. Виберіть потрібний продукт зі списку.
4. Вкажіть вагу продукту в грамах.
5. Перегляньте розраховані калорії та БЖВ.
6. Додайте продукт до списку розрахунку.
7. Повторіть дії для інших продуктів.

Програма автоматично обчислює сумарну калорійність і харчову цінність доданих продуктів.

### Створення власного продукту

1. Відкрийте форму створення продукту.
2. Введіть назву.
3. Вкажіть калорії, білки, жири та вуглеводи на 100 г.
4. Збережіть продукт.

Новий продукт буде доданий до каталогу та збережений у SQLite.

### Редагування та видалення продуктів

Власні продукти можна редагувати та видаляти.

Стандартні продукти каталогу захищені від змін.

### Збереження розрахунків

Додані до списку продукти автоматично зберігаються в локальній базі даних.

Після повторного запуску CalorieCalc попередній список розрахунку відновлюється.

## Зберігання даних

Для роботи з даними використовується SQLite через вбудований модуль Node.js `node:sqlite`.

База даних містить інформацію про:

- стандартні продукти;
- власні продукти користувача;
- збережені записи розрахунку;
- вагу та харчову цінність продуктів.

Основні функції застосунку працюють локально та не потребують підключення до інтернету.

## Тестування

```bash

```

## Збирання застосунку для macOS

Для створення готового застосунку виконайте:

```bash
npm run make
```

Electron Forge створить файли застосунку в папці `out/`.

Поточна збірка перевірена на **macOS з процесором Apple Silicon (arm64)**.

Готовий застосунок можна запускати без VS Code та команди `npm start`.
