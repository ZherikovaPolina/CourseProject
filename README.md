
# CalorieCalc

**CalorieCalc** - настільний застосунок для розрахунку калорійності та харчової цінності продуктів, визначення персональної добової норми калорій і ведення щоденника харчування.

Програма дозволяє обирати продукти з каталогу, вказувати їхню вагу, розраховувати калорії, білки, жири та вуглеводи (БЖВ), а також створювати власні продукти.

Користувач може створити персональний профіль, отримати розрахунок добової норми калорій і БЖВ, відстежувати свій прогрес та вести щоденник харчування з розподілом продуктів за датами й прийомами їжі.

Застосунок має зручний графічний інтерфейс і використовує локальну базу даних SQLite для збереження інформації.

- Створення та збереження персонального профілю користувача.
- Розрахунок добової норми калорій з урахуванням статі, віку, зросту, ваги, фізичної активності та мети.
- Розрахунок добових цілей для білків, жирів і вуглеводів.

## Інструкція користувача

### Створення персонального профілю

1. Запустіть CalorieCalc.
2. Відкрийте розділ персонального профілю.
3. Виберіть стать.
4. Вкажіть вік, зріст і вагу.
5. Оберіть рівень фізичної активності.
6. Вкажіть мету: схуднення, підтримання або набір ваги.
7. Збережіть профіль.

Після збереження профілю програма автоматично розраховує персональну добову норму калорій, білків, жирів і вуглеводів.

Для визначення базового обміну речовин використовується формула Міффліна — Сан Жеора. Розрахунок враховує рівень фізичної активності та обрану мету користувача.

Параметри профілю можна змінювати. Після збереження оновлених даних добові цілі перераховуються.

### Розрахунок калорійності

1. Запустіть CalorieCalc.
2. У полі пошуку введіть назву продукту.
3. Виберіть потрібний продукт зі списку.
4. Вкажіть вагу продукту в грамах.
5. Перегляньте розраховані калорії та БЖВ.
6. Виберіть прийом їжі.
7. Додайте продукт до щоденника.
8. Повторіть дії для інших продуктів.

Програма автоматично обчислює сумарну калорійність і харчову цінність доданих продуктів за вибрану дату.

### Ведення щоденника харчування

Щоденник харчування дозволяє записувати спожиті продукти та переглядати інформацію окремо за кожен день.

Для додавання продукту:

1. Виберіть потрібну дату в календарі.
2. Оберіть прийом їжі.
3. Знайдіть продукт у каталозі.
4. Вкажіть його вагу в грамах.
5. Додайте продукт до щоденника.

Продукти розподіляються за п'ятьма прийомами їжі:

- **Сніданок**
- **Перекус 1**
- **Обід**
- **Перекус 2**
- **Вечеря**

У кожному розділі відображаються додані продукти та загальна калорійність відповідного прийому їжі.

Для швидкого додавання можна скористатися кнопкою **«+ Додати продукт»** у потрібному розділі. Після натискання програма автоматично вибирає відповідний прийом їжі та переходить до форми додавання продукту.

### Перегляд історії харчування

1. Відкрийте календар щоденника харчування.
2. Виберіть потрібну дату або скористайтеся кнопками переходу між днями.
3. Перегляньте продукти, додані за вибраний день.
4. Для повернення до поточної дати скористайтеся кнопкою «Сьогодні».

Записи різних днів зберігаються окремо та не змішуються.

Користувач може додавати й видаляти продукти за вибрану дату. Очищення одного дня не впливає на записи інших днів.

Історія харчування автоматично зберігається в базі даних SQLite.

### Відстеження денного прогресу

Після створення персонального профілю застосунок відображає чотири кругові індикатори:

- **Калорії** - кількість спожитих калорій відносно добової норми.
- **Білки** - кількість спожитих білків відносно добової цілі.
- **Жири** - кількість спожитих жирів відносно добової цілі.
- **Вуглеводи** - кількість спожитих вуглеводів відносно добової цілі.

Індикатори показують прогрес виконання добових цілей, спожиту кількість та залишок до норми.

Якщо добову норму перевищено, застосунок відображає величину перевищення.

Показники оновлюються після додавання або видалення продуктів, зміни дати чи оновлення персонального профілю.

### Створення власного продукту

1. Відкрийте форму створення продукту.
2. Введіть назву.
3. Вкажіть калорії, білки, жири та вуглеводи на 100 г.
4. Збережіть продукт.

Новий продукт буде доданий до каталогу та збережений у SQLite.

### Редагування та видалення продуктів

Власні продукти можна редагувати та видаляти.

Стандартні продукти каталогу захищені від змін.

Продукти, додані до щоденника харчування, можна видаляти окремо з відповідного прийому їжі.

### Збереження розрахунків

Додані до щоденника продукти автоматично зберігаються в локальній базі даних.

Кожен запис містить інформацію про продукт, його вагу, калорійність, БЖВ, дату та прийом їжі.

Після повторного запуску CalorieCalc користувач може вибрати потрібну дату та переглянути збережені записи.

Персональний профіль і власні продукти також зберігаються між запусками застосунку.

## Зберігання даних

Для роботи з даними використовується SQLite через вбудований модуль Node.js `node:sqlite`.

База даних містить інформацію про:

- стандартні продукти;
- власні продукти користувача;
- персональний профіль користувача;
- параметри для розрахунку добових норм;
- збережені записи щоденника харчування;
- дату та тип прийому їжі;
- вагу та харчову цінність продуктів.

Основні таблиці бази даних:

| Таблиця | Призначення |
|---------|-------------|
| `products` | Зберігання стандартних і власних продуктів |
| `user_profile` | Зберігання параметрів персонального профілю |
| `calculation_items` | Зберігання записів щоденника харчування за датами та прийомами їжі |

База даних створюється автоматично під час першого запуску застосунку.

Основні функції CalorieCalc працюють локально та не потребують підключення до інтернету.

## Збирання застосунку для macOS

Для створення готового застосунку виконайте:

```bash
npm run make
```

Electron Forge створює файли застосунку в папці `out/`.

Поточна збірка успішно створена для **macOS з процесором Apple Silicon (arm64)**.

Готовий застосунок:

```text
out/CalorieCalc-darwin-arm64/CalorieCalc.app
```

ZIP-архів застосунку:

```text
out/make/zip/darwin/arm64/CalorieCalc-darwin-arm64-1.0.0.zip
```

Готовий застосунок можна запускати без VS Code та команди `npm start`.
