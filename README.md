
# CalorieCalc

Кросплатформний десктопний застосунок для розрахунку
калорійності харчових продуктів.

## Технології

- Electron
- React
- JavaScript
- HTML
- CSS
- SQLite (заплановано для другого етапу)

## Можливості

- Пошук продуктів
- Вибір продукту
- Введення кількості у грамах
- Розрахунок калорійності та БЖВ
- Додавання продуктів до списку
- Видалення продуктів
- Підрахунок загального результату

## Запуск

Для роботи потрібні Node.js та npm.

Встановлення залежностей:

npm install

Запуск застосунку:

npm start

## Стан розробки

Тиждень 1: створення основи застосунку та
початкового інтерфейсу.

На першому етапі використовуються тестові дані.
Підключення SQLite заплановане на другий тиждень.
